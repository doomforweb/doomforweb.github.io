PORTED TO THE WEBDOOM

linuxdoom-1.10 を WebAssembly に移植したブラウザ版。ゲームデータ（WAD）はご自身のものを読み込んでください。

WAD ファイル

ここに WAD をドロップ、またはタップして選択 IWAD（doom.wad / doom2.wad / freedoom 等）を1つ、必要なら PWAD を追加。複数選択できます。

    サーバー上の WAD

      詳細オプション

      iPhone の Safari では全画面 API が使えません。共有メニューから「ホーム画面に追加」すると全画面で遊べます。

      Doom のソースコードは GNU GPL v2 で公開されています。WAD ファイルは同梱されていません。WAD はブラウザの外には送信されません。
